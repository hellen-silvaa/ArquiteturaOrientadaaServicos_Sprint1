# Arquitetura Orientada a Servicos - Sprint 1

Backend Spring Boot (Java 21) com REST 


## Execucao

```bash
cd /home/hellen/Downloads/ArquiteturaOrientadaaServicos_Sprint1
mvn clean test
mvn spring-boot:run
```

## Documentacao

Toda a documentacao funcional da API REST sera mantida no Swagger/OpenAPI:

- Swagger UI: `http://localhost:8080/swagger-ui.html`
- OpenAPI JSON: `http://localhost:8080/v3/api-docs`

## SOAP

- Endpoint: `http://localhost:8080/ws`
- WSDL: `http://localhost:8080/ws/customerRisk.wsdl`
